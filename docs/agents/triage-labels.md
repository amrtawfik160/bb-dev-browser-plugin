# Triage Labels

The engineering skills use five canonical triage roles. This table maps each role to the GitHub label used by this repository.

| Label in mattpocock/skills | Label in this repository | Meaning                                  |
| -------------------------- | ------------------------ | ---------------------------------------- |
| needs-triage               | needs-triage             | Maintainer needs to evaluate this issue  |
| needs-info                 | needs-info               | Waiting on reporter for more information |
| ready-for-agent            | ready-for-agent          | Fully specified, ready for an AFK agent  |
| ready-for-human            | ready-for-human          | Requires human implementation            |
| wontfix                    | wontfix                  | Will not be actioned                     |

When a skill names a canonical role, use the corresponding repository label from this table.

Edit the right-hand column if the repository later adopts a different label vocabulary.
