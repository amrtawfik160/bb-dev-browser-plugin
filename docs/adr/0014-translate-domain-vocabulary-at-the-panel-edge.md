# Translate domain vocabulary at the panel edge

The Browser Panel presents owner-facing language rather than the domain terms this repository is built on, so Control Lease, Automation Mode, Origin Scope, Project Loopback Alias, and Grant Request identifiers stop appearing verbatim in the interface: a held lease becomes a coloured page border and the agent's purpose, a solitary owner sees no spectator count, a denied origin becomes a question naming that origin rather than a request UUID, and the mode indicator appears only for Safe Login because Automation Mode is by definition the normal mode. `CONTEXT.md` remains the single source of truth for what each term means and the vocabulary stays unchanged in code, tests, CLI output, Activity Records, and documentation, so this is a presentation boundary rather than a renaming. The trade is deliberate: the panel loses one-to-one traceability to the glossary, and a reader who knows the domain can no longer confirm which concept a control maps to without consulting this decision, in exchange for an interface whose every element states something the owner can act on.
