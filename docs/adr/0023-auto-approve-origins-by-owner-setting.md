# Auto-approve origins by owner setting

Default Access (ADR 0015) covers the whole web, but raw localhost stays outside whole-web scope (ADR 0013), so every new local dev server port still ended in `origin_denied` and a Grant Request that stopped the agent until the owner answered it in Browser Settings. Origin Auto-Approval is an owner setting, on by default and switchable in Browser Settings, that answers such a request at once: the request is still recorded, then approved by the system as a persistent exact-origin Profile Grant, so the request history and Activity show the same trail an owner decision leaves (actor `system`, outcome `auto-approved`), and the grant stays visible and revocable. The setting widens origin access only. File transfer and invalid-certificate access keep their explicit opt-ins; a project whose Default Access the owner withdrew, a project with an expired time-limited whole-web grant, and a deleted project keep the request flow; profile isolation, Safe Login, and redaction are unchanged. Turning the setting off restores the ADR 0013 behaviour for new origins without revoking grants already approved. For `chrome-devtools-axi`, which needs the whole web (ADR 0022), opening a raw localhost URL now checks the localhost origin and the project's whole-web access separately instead of requiring the localhost grant itself to be whole-web.
