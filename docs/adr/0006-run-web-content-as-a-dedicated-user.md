# Run web content as a dedicated user

Chrome and its display helpers run as a dedicated unprivileged `bb-browser` operating-system user with Chrome's sandbox enabled, even when BB itself runs as root; running authenticated web content as root with `--no-sandbox` is unsupported. Profile data lives in an installation- and host-scoped namespace under `/var/lib/bb-browser` with owner-only permissions and stable profile identifiers rather than under root's plugin or `dev-browser` data. Chrome's storage protections and host disk encryption remain the at-rest boundary: the plugin does not add an unattended key layer, and saved passwords, address/payment autofill, extensions, and Sync are disabled. Official Chrome Stable is preferred for login compatibility, with pinned Playwright Chromium available as a fallback for ordinary browsing. Before the privileged copy sees the fallback, a private descriptor-anchored staging pass accepts only regular files and directories and rejects symlinks and special files; the privileged copy then applies ordinary `bb-browser` ownership and normalized safe modes. Setup never promotes mutable Playwright-cache content into a root-owned setuid helper. Fallback sandbox readiness therefore relies on user namespaces or a separately validated system helper.
